# Gemini Strategy Advisor

`SmartAgentWithGemini` uses the existing `DecisionEngine` and hard constraints. An external async caller prewarms an offer with `await agent.service.advisor.prewarm(order, agent.snapshot)` before `decide_request(order)`. `/decide` only reads the process-local cache; it never calls Gemini. An advisory is specific to the observable offer and historical snapshot version, with an hour bucket and simulated-time TTL. An environment passed to prewarm must also be supplied to cache lookup; the current `/decide` contract has no environment field, so its environment is `null`. No RNG, generator, future offers, future shocks or held-out events are serialized. The current position and load are `null` if unavailable.

The official `google-genai` Python SDK uses `genai.Client`, `client.aio.models.generate_content`, and Pydantic `response_json_schema`. Default model: `gemini-3.6-flash`. Set `GEMINI_ENABLED=true`, `GEMINI_API_KEY`, optionally `GEMINI_MODEL`, `GEMINI_TIMEOUT_MS` (default 10000), `GEMINI_MAX_RETRIES` (default 0), `GEMINI_ADVISORY_TTL_SIM_MIN` (default 10), `LLM_MIN_ADJUSTMENT_MXN_HR` (default -20), and `LLM_MAX_ADJUSTMENT_MXN_HR` (default 20). Never put the key in committed files.

The exact strategy prompt is `STRATEGY_SYSTEM_PROMPT` in `app/llm/prompts.py`. Structured output is `StrategyAdvice`: recommendation ACCEPT/SKIP/NEUTRAL, confidence in [0,1], demand outlook LOW/MEDIUM/HIGH, destination quality POOR/NEUTRAL/GOOD, opportunity risk LOW/MEDIUM/HIGH, key factors as strings and explanation as a string. Malformed output, missing key, timeout, network error or quota error leaves adjustment zero. A failed refresh may still use an unexpired cached advisory. When enabled without a valid advisory, `degraded=true`.


Adjustment formula: `clamp(confidence * (5*recommendation + 5*demand + 5*destination + 5*risk), min, max)` in MXN/hr, where ACCEPT/HIGH/GOOD/LOW risk are +1; SKIP/LOW/POOR/HIGH risk are -1; other values are zero. NEUTRAL recommendation forces zero. Defaults clamp to [-20,+20]. Hard constraints run before this formula. The log preserves original structured reason, both rate scores, advisory, adjustment, cache status and error. A post-decision asynchronous explanation is validated against logged numeric facts; unsupported numbers or future claims cause a null explanation.

`SmartAgentNoLLM` and `SmartAgentWithGemini` are selectable agent classes. Existing simulator behavior does not schedule prewarming automatically. To evaluate incremental value, prewarm observable offers in a separate async stage, replay the same tuning seeds with both agents and the unchanged FirstNearbyOrderBaseline, then compare net earnings, distance, lateness and safety. Do not tune on held-out seeds. `net_gain_from_llm_changed_decisions` remains null until paired counterfactual shift accounting is performed; decision changes alone do not prove gain. Live Gemini latency and outcomes require an API key and were not measured in this checkout. The process-local cache does not persist across restarts or workers.

For API use, call `POST /strategy/advisory/prewarm` with the same `DecideRequest` body before `POST /decide`. Prewarming may take up to the configured Gemini timeout and is intentionally outside the decision path. A cache miss in `/decide` gives zero adjustment. The explanation is scheduled after the response and can be read later from `GET /decisions/{order_id}`; it may remain null when grounding validation rejects the text.

## Natural explanations in the visual demo

The visual simulator still compares `FirstNearbyOrderBaseline` with deterministic `SmartAgent`; Gemini does not change either agent's choices there. After an order becomes visible, the UI can request `GET /demo/simulations/{id}/decisions/{order_id}/explanation`. The request sends only the already-recorded Smart decision, binding constraint, reason and economics to Gemini. Prompt-only numeric facts are rounded to two decimal places; original decision logs retain full precision. The endpoint caches one explanation per session, simulation revision and order; it never blocks simulation preparation or playback. The UI shows a natural English explanation on demand in the order card, Smart panel or Smart history, with the original technical reason available separately and formatted to two decimal places. If Gemini fails, responds in Spanish, or invents an unsupported number, the endpoint returns a deterministic English fallback. The original simulator log and decision are unchanged.
